## 1. 一句话定位

**VeriAgent = 可验证的链上 AI Agent 资产管理原语**：把 AI Agent 的每一笔交易决策变成链上可审计的凭证，Agent 在智能合约约束的"金库"内自主管理代币化资产（bStocks/RWA）。

## 2. 解决什么真实问题

**问题**：机构和用户不敢让 AI Agent 自主管钱——决策黑箱、权限不可控、出事无法追责。

**现状三个痛点**：
1. **黑箱交易**：Agent 为什么买/卖无法证明，事后无法审计
2. **权限失控**：Agent 拿到 API key/私钥等于全权委托，无硬性约束
3. **责任缺位**：Agent 服务无身份、无信誉、无交易历史

**VeriAgent 的答案**：
- 每笔交易 = 链上决策记录（reason hash + 数据源 hash）→ **可审计**
- Agent 只有 Session Key，策略由 Vault 合约硬性执行（白名单/仓位上限/日亏损熔断）→ **可约束**
- 每个 Agent 有 ERC-8004 身份 + ENS 名字 + 链上信誉分 → **可追责**

## 3.1 RWA 合规对齐：SEC Innovation Exemption（2026-09-17）

2026-09-17 SEC 发布 5 年期「创新豁免令」，为代币化美股创设 **TSV（Tokenized Securities Venue）** 类别：
真实股票 1:1 代币化可在许可制 AMM/流动性池上链交易，无需注册为国家证券交易所。核心条件与 VeriAgent 的对应：

| SEC TSV 条件 | VeriAgent 实现 |
|---|---|
| **No Synthetics**：代币须保留分红+投票权（与传统股等同） | `TokenizedEquity.onchain_rights=True` 标记；股息流转经 `run_dividend`→`dividend_ack` 凭证+链上 `notifyDividend`/`DividendReceived` 事件双重审计 |
| **停牌联动**：主市场 halt 时代币同步停牌 | `MarketSession.HALTED` 硬门控 → `DecisionReject("MARKET_HALTED")`，凭证不生成、交易不可达 |
| **闭市流动性管理**：24/7 场外时段薄流动性 | `MarketSession.CLOSED` → 风险分 +3000bps 溢价 + spread 容忍度调整，决策理由含 `session=CLOSED` 上链存证 |
| **发行人权利+透明**：10 分钟内公布交易数据 | 每笔决策四哈希（action/reason/dataSource/model）+ JSONL 哈希链，context_hash 内嵌 session 状态 |
| **交易限额**（Tier 1: 75 标的/0.25% ADV） | Vault `maxPositionPctBps`+`maxTradesPerDay`+`dailyLossLimitBps` 策略引擎 |

Robinhood Chain（Arbitrum Orbit）上的 bStocks 是该赛道旗舰产品——VeriAgent 的引擎+合约层已按 TSV 合规约束设计。

## 3.2 AI 决策模型审计层：Jev (TypeSafe System One) 集成

TypeSafe AI 于 2026-09-16 发布 Jev——首个 System One Model：**不生成文本，只输出类型化决策+校准置信度**（$42/B tokens，比 LLM 快 193x/便宜 444x，结构上零幻觉；ChatGPT 联创出品）。48 小时内 jarrodwatts/jev-trader（1.1k stars）等项目把 Jev 决策**直连链上订单簿**——每个 Monad block 一次 buy/sell，无任何审计。

**这正是 VeriAgent 的信任缺口**：Jev 说 buy 就 buy——决策依据在哪？谁在事后能验证？VeriAgent 作为审计层的集成架构：

```
市场快照 → JevModel.decide() → JevDecision {action, confidence}
   → DecisionPolicy（confidence → risk_score 反向映射；session 门控不变）
   → Decision 四哈希凭证（model_id="jev-systemone"，reason 内嵌 confidence）
   → DecisionRecorder 上链 + JSONL 哈希链
```

- Jev 决策与任何其他模型走**同一条凭证流水线**——modelHash 在链上区分决策来源
- **合规 > 模型**：Jev 置信度再高，HALTED 时段一律 `MARKET_HALTED` 拒单（SEC 停牌联动条件在模型之前生效）
- confidence 校准值完整保留在决策记录中——审计者可以看到模型自己的不确定性
- 传输层不臆造：Jev 处 early access waitlist，API endpoint 以官方文档（docs.typesafe.ai）为准，MockJevModel 按官方输出契约全功能演示

测试：13 项 Jev 集成测试（决策契约/置信度映射/审计凭证/HALT 门控优先级/model_hash 血统）全绿。

## 4. 产品形态

```
用户存入 USDC/bStocks → 选择策略 Agent → Vault 按策略约束托管
                                          │
Agent 循环：感知行情 → LLM 决策 → 决策凭证上链 → Session Key 执行调仓
                                          │
任何第三方可通过 Explorer 验证：每笔交易的决策依据完整可查
```

三个用户可见组件：
1. **Vault 金库**：用户存钱，策略约束由合约保证
2. **Agent 市场**：注册 Agent 列表 + 信誉分 + 历史审计报告
3. **Audit Explorer**：决策凭证查询/验证界面
